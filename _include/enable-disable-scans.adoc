You can start or stop scans on any system at any time from the Configuration menu. You can also switch scans from map-only scans to full scans, and vice-versa. 

The option to *Scan without write permissions* is disabled by default. This means that if Data Classification does not have appropriate write permissions, the system will not scan the files because Data Classification cannot revert the "last accessed time" to the original timestamp. If your system can tolerate the last accessed time being modified, select this option. link:reference-collected-metadata.html#last-accessed-time-timestamp[Learn more^].

[NOTE]
New volumes added to the system are automatically scanned only when you have enabled scanning for all volumes. If you have only enabled scanning on certain volumes, you must manually enable scanning on the newly added volume. 

image:screenshot_volume_compliance_selection.png[A screenshot of the Configuration page where you can enable or disable scanning of individual volumes.]

.Steps 

. From the Data Classification menu, select *Configuration*.
. Identify the system you want to scan. Select **Activate scan**. In the dropdown, choose **Scan all volumes: full scan**, **Scan all volumes: mapping only**, or **Manage scans** to open the system menu and configure scanning on specific volumes. 
+
To enable or disable scans for individual volumes, find the volumes in the list. In the scan type column, select **Map only** or **Full scan**. 

.Result

When you enable scanning, Data Classification starts scanning the volumes you selected in the system. Results start to appear in the Compliance dashboard as soon as Data Classification starts the scan. Scan completion time depends on the amount of data, ranging from minutes to hours.
